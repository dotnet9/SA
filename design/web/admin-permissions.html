权限模型说明
功能点（function point）是全系统最小的授权单位，采用「角色 → 功能点」的多对多关系（对应后续数据库的 Role / FunctionPoint / RoleFunctionPoint 三张表）。 后端用策略式授权在 API 层校验，前端按同一份配置裁剪路由与菜单，避免「看不到但能调」的漏洞。 本页勾选即时写入本地配置并影响左侧导航，用于直观演示权限效果。
