移动端设计规范 Web 规范
移动端与 Web 端共用同一套设计令牌与组件样式（tokens.css / components.css）， 差异只在布局：Web 用左侧导航 + 三栏，移动端用底部 Tab + 单列流。 本页只列移动端特有的规则与检查项。
1. 画布与安全区
设计尺寸390 × 844（iPhone 14/15 逻辑分辨率）
最小支持宽度320px（iPhone SE 一代）
左右安全边距16px（.m-page）
顶部状态栏44px（原型外框模拟）
底部 Tab 栏56px + 安全区（env(safe-area-inset-bottom)）
吸顶元素行情条 / 顶栏 / Tab 使用 position: sticky

4. 移动端特有交互
左滑列表行左滑露出「提醒 / 移除」，阈值 60px，最大位移 136px
长按长按列表行进入拖拽排序（自选股）
下拉刷新通知中心、自选股列表顶部下拉
双指捏合K 线、拓扑图、风险矩阵缩放
底部抽屉条件编辑、指标切换（.sheet），最大高度 78vh
全屏页新建提醒规则走全屏步骤式，比对话框更好点按

Toast底部居中，2.6 秒自动消失，避免遮挡底部 Tab

6. 移动端图表规范
坐标轴字号10–11px（比 Web 端小 1px）
默认图表高度200–340px（单屏内不滚动即可看完）
K 线高度300px（含成交量副图）
拓扑图高度300–340px，节点标签超 5 字截断
图例能省则省；必须保留时置于图表下方一行
tooltip改为「点击/长按显示」并贴近手指上方，避免遮挡
手势单指平移 · 双指缩放 · 长按十字光标
数据口径每个图表下方必配 .chart-note 或 .legend-block
7. 与 Web 端的差异清单
导航Web 左侧 240px 导航 → 移动端底部 5 个 Tab
布局Web 三栏 / 多列网格 → 移动端单列卡片流
表格Web 完整列 → 移动端精简列 + 横向滚动 + 首列冻结
批量操作Web 勾选 + 批量按钮 → 移动端左滑 / 长按
对话框Web 居中对话框 → 移动端底部抽屉或全屏页
列设置Web 列配置菜单 → 移动端固定精简列，不做配置
后台管理仅 Web 端提供，移动端不做管理功能
演示数据角标Web 右下角固定 → 移动端置于屏幕内右下、Tab 栏上方
自检清单
① 所有可点击元素热区 ≥ 44×44；
② 390×844 内无横向滚动条（刻意设计的宽表格除外）；
③ 每个图表下方有数据口径说明；
④ 底部 Tab 栏常驻且当前页高亮；
⑤ 数字列等宽右对齐；
⑥ 深浅主题与涨跌色切换在全部页面生效。

全屏页示例
复杂表单（如新建提醒规则）用全屏页而非对话框：步骤可分段、字段可堆叠、底部按钮可固定在安全区内， 在窄屏上点按准确率明显更高。
