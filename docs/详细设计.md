## 1. 通用约定

### 1.1 响应包

```json
{ "code": 0, "message": "ok", "data": { }, "traceId": "a1b2c3d4" }
```

| 字段 | 说明 |
|---|---|
| `code` | 0 成功；非 0 为业务错误码 |
| `message` | 面向用户的简短提示（可直接展示） |
| `data` | 业务数据，失败时为 `null` |
| `traceId` | 便于日志排查 |

### 1.2 错误码

| 码 | 含义 | HTTP |
|---|---|---|
| 0 | 成功 | 200 |
| 1001 | 参数校验失败 | 400 |
| 1002 | 资源不存在（如股票代码） | 404 |
| 1003 | 数据尚未就绪（采集中） | 409 |
| 2001 | 未登录或令牌失效 | 401 |
| 2002 | 无该功能点权限 | 403 |
| 2003 | 超出数据范围（仅自选） | 403 |
| 2004 | 登录失败次数过多，账号锁定 | 423 |
| 3001 | 数据源不可用（已降级） | 503 |
| 3002 | 查询超出配额 | 429 |
| 4001 | 导出权限未开启 | 403 |
| 9999 | 未预期异常 | 500 |

### 1.3 其他约定

| 项目 | 约定 |
|---|---|
| 时间 | `Asia/Shanghai`，字符串 `yyyy-MM-dd` 或 `yyyy-MM-dd HH:mm:ss` |
| 金额单位 | 亿元（`amount`、`revenue`、`netProfit` 等字段均以亿元计） |
| 比率 | 百分数直接给数值（`pct: 4.86` 表示 +4.86%），不乘 100 |
| 影响强度 | 整数 0–100，负值表示压制方向 |
| 分页 | `page`（1 起）、`pageSize`（默认 20，最大 200），返回 `total` |
| 排序 | `sort=field:asc\|desc`，字段名与 DTO 同名 |
| 字段命名 | camelCase；与原型 `data.js` 保持一致，降低迁移成本 |
| 幂等 | 自选增删、规则启停均幂等 |

## 5. 指标算法

### 5.1 均线与 MACD

```
MA(n)[i] = mean(close[i-n+1 .. i])                         i >= n-1，否则为 null
EMA(n)[0] = close[0];  EMA(n)[i] = close[i]*k + EMA(n)[i-1]*(1-k),  k = 2/(n+1)
DIF  = EMA(12) - EMA(26)
DEA  = EMA(DIF, 9)
MACD = (DIF - DEA) * 2
```

### 5.2 KDJ(9,3,3)

```
RSV[i] = (close[i] - LLV(low, 9)[i]) / (HHV(high, 9)[i] - LLV(low, 9)[i]) * 100   （分母为 0 时取 50）
K[i] = (2/3) * K[i-1] + (1/3) * RSV[i]        K 初值 50
D[i] = (2/3) * D[i-1] + (1/3) * K[i]          D 初值 50
J[i] = 3*K[i] - 2*D[i]
```

### 5.3 相对强弱与分位

```
相对强弱[i] = (个股累计收益[i] / 个股累计收益[0] - 1) - (沪深300累计收益[i] / 基准[0] - 1)
价格分位 = 排序后 close 分布中，小于等于当前价的样本占比 × 100
```

### 5.4 筹码分布（估算）

```
初始化 chips[priceBucket] = 0
for 每根历史 K 线 bar：
    将 bar.volume 按 [low, high] 均匀分配到覆盖的价格档位
    对全部档位衰减：chips[p] *= (1 - turnover[bar])
归一化使 Σchips = 1
平均成本   = Σ(p * chips[p])
获利盘比例 = Σ(chips[p] for p < 现价)
集中度     = (P90 - P10) / (P90 + P10)，其中 Pn 为筹码累计分布的分位价
```

### 5.5 财务增速

```
同比 = (本期 − 上年同期) / |上年同期| × 100
环比 = (本期 − 上一季度) / |上一季度| × 100
单季度 = 累计(n) − 累计(n−1)；Q1 直接取累计值
净现比 = 经营现金流 / 净利润
收现比 = 销售商品收到的现金 / 营业收入
```

### 5.6 财务健康评分

各维度取该指标在全行业中的分位，按权重加权（盈利 30%、成长 20%、现金流 20%、偿债 15%、营运 15%），输出 0–100。
界面标注为「按行业分位加权」，非评级机构评分。

### 6.2 退避与降级

| 场景 | 处理 |
|---|---|
| HTTP 429 / 5xx | 指数退避（1s → 2s → 4s，最多 3 次），失败记入 `CollectTaskLog` |
| 连续失败 ≥ 3 次 | 标记数据源为 `warn`，切换备用源（腾讯 → 新浪 → 东方财富） |
| 字段结构变更 | 解析失败时记录原始响应片段并告警「字段结构变更」 |
| PDF 解析失败 | 加入待重试队列，次日重跑 |

### 6.3 调度

- 使用交易日历判断是否为交易日；非交易日只跑「连通性探测」与「数据源监控」。
- 盘中任务使用 `PeriodicTimer`；盘后任务使用 Cron 表达式。
- 所有任务执行前后写 `CollectTaskLog`，并更新 `DataSourceStatus`。

## 8. 授权实现

```csharp
[AttributeUsage(AttributeTargets.Method | AttributeTargets.Class)]
public sealed class RequireFunctionPointAttribute : Attribute {
    public string[] Codes { get; }
    public RequireFunctionPointAttribute(params string[] codes) => Codes = codes;
}
```

- 授权处理器读取当前用户角色 → 功能点集合（登录时载入并缓存，权限变更时失效）。
- 数据范围策略：`data.scope.watchlist` 时，查询管道自动注入「仅自选股」过滤。
- 配额：`quota.daily` 按账号 + 自然日计数（内存 + 落库），超限返回 3002。
- 前端裁剪：`/api/me/permissions` 返回功能点数组与配额，前端据此过滤路由与菜单。

### 9.2 图表封装契约

```ts
type ChartFactory =
  | "spark" | "kline" | "combo" | "stacked" | "posneg" | "area" | "donut"
  | "radar" | "sankey" | "graph" | "heatmap" | "bubble" | "targetBand"
```

要点：
- 颜色全部从 CSS 变量解析（`getComputedStyle`），主题或涨跌色变更后**重建实例**（对应原型 `rebuildAll`）。
- **同一容器重复绘制前必须 dispose 旧实例**（原型已实现该保护，避免实例泄漏与控制台告警）。
- 组件卸载时 dispose；容器尺寸变化用 `ResizeObserver` 触发 `resize()`。
- K 线默认展示最近 120 根，最多 240 根；`dataZoom` 使用 inside 模式。

## 11. 日志与错误处理

| 类型 | 处理 |
|---|---|
| 采集日志 | 结构化落文件（按天滚动，保留 7 天），按 `INFO/WARN/ERROR` 分级，界面可按级别过滤 |
| 业务异常 | 转错误码返回，`message` 可直接展示给用户 |
| 未预期异常 | 返回 9999 并记录 `traceId`，界面提示「请稍后重试」 |
| 权限异常 | 返回 2002/2003，前端提示并回退到上一个有权限页面 |
| 数据未就绪 | 返回 1003，界面展示「采集中」状态并允许重试 |
| 全局兜底 | 前端错误边界捕获渲染异常，展示错误卡片与刷新入口 |

## 12. 性能要点

| 项 | 措施 |
|---|---|
| 全市场快照 | 只保留必要字段的紧凑结构；盘中每 3s 整体替换而非逐条更新 |
| 分析查询 | 路由级缓存 5 分钟；同一股票并发请求合并（请求去重） |
| 时序读取 | Parquet 按标的 + 分区读取，只取所需列；DuckDB 直接 SQL 聚合 |
| 图表 | 序列点数上限（K 线 240、分位图 120）；关闭入场动画或缩短至 300ms |
| 首屏 | 前端按路由分包；ECharts 按需引入图表类型与组件 |
| SQLite | WAL 模式；读多写少场景避免长事务；关键查询建立覆盖索引 |
| 移动端 | 失焦降频；列表虚拟化（自选股 > 100 只时） |
